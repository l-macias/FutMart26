# Visual Direction

## Direction

**Night Match + Tactical + Collectible**

The application should feel like a football product/game, not a generic dashboard with football labels.

## Desired impression

- amateur night football;
- floodlights;
- tactical board;
- match-day energy;
- collectible/player cards;
- progression;
- competitive but social.

## Avoid

- generic SaaS dashboard look;
- default white rounded cards everywhere;
- purple/blue AI gradients;
- standard icon pack as the main personality;
- excessive pills;
- arbitrary glassmorphism;
- stock "gaming" neon everywhere;
- direct visual copying of EA FC/FIFA, Sofascore, betting apps or existing brands.

## Color strategy

Do not make "green" the entire brand merely because the product is football.

Suggested structural direction:

- graphite/charcoal neutral foundation;
- distinctive primary sport accent;
- pitch green as contextual color;
- amber/gold family for progression/highlights;
- red reserved for destructive/negative/error semantics;
- tier-specific card palettes.

Exact palette must be chosen and tokenized during visual prototype.

## Typography

Use two roles:

### Display / Sport

For:

- OVR;
- score;
- headers;
- cards;
- match states;
- awards.

Traits:

- strong;
- condensed or compact;
- numeric presence;
- distinctive.

### Interface

For:

- body;
- forms;
- settings;
- metadata;
- accessibility-critical text.

Traits:

- highly readable;
- neutral enough not to compete with display typography.

Exact fonts remain to be selected during visual exploration.

## Football-specific language

Use product-specific visual metaphors:

- pitch markings;
- tactical lines;
- lineup nodes;
- jersey-number scale;
- scoreboard numerics;
- match-state treatments;
- progression markers.

Do not overdecorate every surface.

## Hierarchy of excitement

Normal screens: restrained.

Important moments:

- promoted from waitlist;
- voting results;
- tier/card upgrade;
- award/achievement.

Celebration is reserved for moments that deserve it.

## Home

Home must feel alive and football-centric.

It should briefly explain the product while showing:

- rankings;
- progression;
- ecosystem activity;
- paths into the game.

## Match screens

The match lifecycle should visually evolve:

- open;
- full;
- waitlist;
- in progress;
- roster confirmation;
- voting open;
- results.

Status must feel like part of a sporting event, not database badges.

## Superadmin

Use the same brand foundation but a more operational visual language.

Configuration screens prioritize:

- legibility;
- comparison;
- audit;
- safe editing;
- preview/simulation.

No forced game-like presentation for technical controls.
